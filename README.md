# log-parser-agent

底软日志分析 AGENT 前端原型，面向嵌入式通信 Linux 单板日志上传、故障上下文采集与 Agent 实时分析过程展示。

## 功能亮点

- 日志文件上传：支持 `.log`、`.txt` 以及 `.zip`、`.tar`、`.gz`、`.tgz`、`.bz2`、`.xz`、`.7z`、`.rar` 等常见压缩格式。
- 必填问题描述：引导用户填写故障现象、发生时间、影响业务等关键信息。
- 基础信息采集：支持板类型、单板/主控角色、CPU 类型、通信制式、软件版本/构建号等输入。
- 实时分析过程：点击“开始智能分析”后，以进度条和阶段卡片模拟展示 Agent 解包、画像、链路识别、根因推理与修复建议生成过程。
- 科技风页面设计：使用深色玻璃拟态、通信信号、芯片与 AI 轨道视觉元素提升观感。

## 本地运行

```bash
npm install
npm run dev:public
```

访问 `http://localhost:4173/` 查看页面。注意：`172.30.*` 这类地址通常是容器内网地址，外部浏览器无法直接访问；如果在远程开发环境中预览，请使用平台提供的端口转发/Preview URL 映射到 `4173` 端口。

## 生产构建

```bash
npm run build
npm run preview:public
```
